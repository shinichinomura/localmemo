# localmemo

ブラウザだけで動く、書き捨てのメモ帳。保存も送信もユーザー登録もありません。

## 特徴

- **データはサーバーへ送らない** — 通信は Content-Security-Policy（`connect-src 'none'` など）でブラウザレベルで禁止。localStorage / Cookie などの永続化も一切使わない
- **QR コードでスマホへ渡せる** — 「QRコードでスマホへ」ボタンで表示される QR を読み取るだけ
- **履歴を持たない** — タブを閉じれば消える。URL にも残らない
- **依存はゼロ** — 静的ファイル 4 つだけ。ビルド不要、どこにでも置ける

## 使い方

1. `index.html` をブラウザで開く（ローカルファイルのままでも動きます）
2. メモを書く
3. 「QRコードでスマホへ」→ スマホのカメラで読み取る

### QR の 2 つのモード

| モード | スマホ側の動き | 向いている場面 |
|---|---|---|
| リンク | このアプリがスマホで開き、本文が入った状態になる | アプリを Web に置いている。長めの文章 |
| テキストそのまま | カメラアプリに本文がそのまま表示される | ホスティングしていない。短い ID やパスワード |

「リンク」モードは、本文を deflate 圧縮して URL の `#` 以降（フラグメント）に載せます。
フラグメントはブラウザが HTTP リクエストに含めない領域なので、ホスティング先のサーバーにも本文は届きません。
受け取った側は読み込んだ直後に `#` 以降を URL から消すため、アドレスバーやブラウザ履歴にも本文が残りません。

## ホスティング

静的ファイルを置ければどこでも動きます（GitHub Pages、Cloudflare Pages、S3、社内の静的サーバーなど）。
「リンク」モードで作られる URL は、開いているページの URL がそのまま使われます。
ローカル確認は次のコマンドで:

```sh
python3 -m http.server 8765
# → http://127.0.0.1:8765/
```

## 制限

- 1 枚の QR に入るのは最大 2,953 バイト（バージョン 40・誤り訂正 L）。日本語なら「テキストそのまま」で約 980 文字、「リンク」は圧縮率次第です。超えると画面で案内します
- QR が大きくなるほど読み取りづらくなります。長文は分割してください
- 圧縮には `CompressionStream` を使います（Chrome 103+ / Safari 16.4+ / Firefox 113+）。未対応ブラウザでは無圧縮で URL を作ります

## ファイル構成

```
index.html        画面と CSP
style.css         見た目（ダークモード対応）
app.js            圧縮・QR 生成・URL からの復元
vendor/qrcode.js  QR 生成ライブラリ（qrcode-generator 1.4.4, MIT, Kazuhiko Arase）
```
